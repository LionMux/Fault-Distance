# Этап 1: Центрирование по предыстории (center_by_prehistory)

## Назначение
Устранение постоянного смещения (offset) сигнала на основе первых 20 мс записи (предыстория до КЗ).

## Математика

Для одноканального сигнала `x[n]` длины `N`:

```
pre_window = round(fs · 0.020)   // число отсчётов в 20 мс

μ = (1/pre_window) · Σ_{n=0}^{pre_window-1} x[n]   // среднее предыстории

x̃[n] = x[n] - μ,   n = 0, 1, ..., N-1
```

## Для многоканального сигнала
Если `X` — матрица размера `(C, N)` (C каналов, N отсчётов):

```
для каждого канала c = 0, ..., C-1:
    μ_c = (1/pre_window) · Σ_{n=0}^{pre_window-1} X[c, n]
    X̃[c, n] = X[c, n] - μ_c
```

## Параметры
| Параметр | Значение | Описание |
|---|---|---|
| `pre_ms` | 20.0 | Длина предыстории [мс] |
| `fs` | из CSV | Частота дискретизации [Гц] |

## Пример
При `fs = 5000` Гц:
- `pre_window = round(5000 · 0.020) = 100` отсчётов
- Среднее вычисляется по первым 100 отсчётам
- Вычитается из всего сигнала

## Свойства
- **Линейная операция**: сохраняет форму сигнала
- **Без фазовых искажений**: не использует фильтрацию
- **Устраняет DC offset**: выравнивает сигнал относительно нуля
- **Не влияет на амплитуду**: только смещение по вертикали
