# Этап 7: Финальный формат тензора

## Форма тензора
```
X: (NUM_CHANNELS, SEQ_LENGTH)
```

где:
- `NUM_CHANNELS` = 6 (без symseq) или 12 (с symseq)
- `SEQ_LENGTH` = 400 (по умолчанию)

## Разметка каналов

### 6-канальный тензор (SYMSEQ_ENABLED = False)
```
X[0, :] = IA   // ток фазы A [нормировано]
X[1, :] = IB   // ток фазы B [нормировано]
X[2, :] = IC   // ток фазы C [нормировано]
X[3, :] = UA   // напряжение фазы A [нормировано]
X[4, :] = UB   // напряжение фазы B [нормировано]
X[5, :] = UC   // напряжение фазы C [нормировано]
```

### 12-канальный тензор (SYMSEQ_ENABLED = True)
```
X[0, :]  = IA      // ток фазы A [нормировано]
X[1, :]  = IB      // ток фазы B [нормировано]
X[2, :]  = IC      // ток фазы C [нормировано]
X[3, :]  = |I1|    // магнитуда прямой последовательности тока [нормировано]
X[4, :]  = |I2|    // магнитуда обратной последовательности тока [нормировано]
X[5, :]  = |I0|    // магнитуда нулевой последовательности тока [нормировано]
X[6, :]  = UA      // напряжение фазы A [нормировано]
X[7, :]  = UB      // напряжение фазы B [нормировано]
X[8, :]  = UC      // напряжение фазы C [нормировано]
X[9, :]  = |U1|    // магнитуда прямой последовательности напряжения [нормировано]
X[10, :] = |U2|    // магнитуда обратной последовательности напряжения [нормировано]
X[11, :] = |U0|    // магнитуда нулевой последовательности напряжения [нормировано]
```

## Batch-формат (для DataLoader)
```
X_batch: (BATCH_SIZE, NUM_CHANNELS, SEQ_LENGTH)
```

## Метка (target)
```
y: scalar float32

// Для standard нормализации:
y_norm = (y_km - d_min) / (d_max - d_min)

// Для p.u. нормализации:
y_pu = y_km / L_km
```

## Пример
При `BATCH_SIZE = 32`, `NUM_CHANNELS = 12`, `SEQ_LENGTH = 400`:
```
X_batch: (32, 12, 400)   // float32
y_batch: (32, 1)         // float32
```

## Вход модели
Модель PyTorch (Conv1d) ожидает:
```python
# (B, C, L) — batch, channels, length
input_tensor: (BATCH_SIZE, NUM_CHANNELS, SEQ_LENGTH)
```

## Примечания
- Все каналы независимо нормированы
- Симметричные составляющие вычислены скользящим окном (time-varying)
- Паддинг/обрезка гарантирует фиксированную длину SEQ_LENGTH
- Данные готовы для подачи в 1D-CNN / ResNet1D
