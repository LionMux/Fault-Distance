# Этап 2: Удаление апериодической (DC) составляющей (remove_dc_period)

## Назначение
Удаление медленно затухающей апериодической составляющей (DC offset), возникающей при коротком замыкании, путём вычитания скользящего среднего за один период сети.

## Математика

### Период сети в отсчётах
```
period = round(fs / f_net)
```

где:
- `fs` — частота дискретизации [Гц]
- `f_net` — сетевая частота (50 или 60 Гц)

### Скользящее среднее (rolling mean)
Для каждого отсчёта `n` вычисляется среднее по окну длины `period`, центрированному на `n`:

```
aper[n] = (1/period) · Σ_{k=n-half}^{n+half} x[k]
```

где `half = period // 2`.

На границах (первые и последние `half` отсчётов) используется экстраполяция среднего по ближайшему полному окну.

### Результат
```
y[n] = x[n] - aper[n]
```

## Реализация (pandas)
```python
s = pd.Series(x)
aper = s.rolling(window=period, center=True, min_periods=1).mean()
# Граничные условия
aper.iloc[:half] = aper.iloc[half:period].mean()
aper.iloc[-half:] = aper.iloc[-period:-half].mean()
y = x - aper.values
```

## Параметры
| Параметр | Значение | Описание |
|---|---|---|
| `fs` | из CSV | Частота дискретизации [Гц] |
| `f_net` | 50.0 | Сетевая частота [Гц] |

## Пример
При `fs = 5000` Гц, `f_net = 50` Гц:
- `period = round(5000 / 50) = 100` отсчётов
- Окно: 100 отсчётов = 20 мс = 1 период 50 Гц
- Скользящее среднее вычитается из исходного сигнала

## Свойства
- **Без фазовых искажений**: симметричное окно (center=True)
- **Сохраняет основную гармонику**: период окна равен периоду сети
- **Удаляет апериодику**: скользящее среднее за период подавляет постоянную составляющую
- **Эквивалентно high-pass фильтру** с частотой среза ~`f_net`

## Сравнение с Butterworth
| | `remove_dc_period` | Butterworth high-pass |
|---|---|---|
| Фазовые искажения | Нет | Есть (нелинейная ФЧХ) |
| Амплитудные искажения | Минимальные | Зависят от порядка и fc |
| Вычислительная сложность | O(N·period) | O(N·log N) или O(N·order) |
| Параметры | fs, f_net | fs, fc, order, type |
