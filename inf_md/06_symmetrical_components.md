# Этап 5: Симметричные составляющие (sliding_window_symseq)

## Назначение
Вычисление time-varying магнитуд симметричных составляющих (прямая, обратная, нулевая последовательности) для токов и напряжений.

## Математика

### 5.1. Скользящее окно DFT

Для каждого момента времени `t` (от 0 до T-1):

```
window_len = period · window_cycles   // период = fs/f_net, обычно window_cycles=1
half = window_len // 2

start = max(0, t - half)
end   = min(T, start + window_len)

// Корректировка границ
если end - start < window_len и start > 0:
    start = end - window_len

w = sig[:, start:end]   // (6, W) — 6 каналов, W отсчётов в окне
```

### 5.2. Оконное FFT

Применяется оконная функция Ханна (Hann window):

```
hann[n] = 0.5 · (1 - cos(2πn / (W-1))),   n = 0, ..., W-1

w_windowed = w · hann   // поэлементное умножение
```

DFT:
```
X[k] = Σ_{n=0}^{W-1} w_windowed[n] · e^(-j·2π·k·n/W)
```

Индекс основной гармоники:
```
k = round(f0 · W / fs)
```

### 5.3. Нормировка фазора

```
phasor = X[k] · (2 / Σ hann)
```

где:
- `X[k]` — комплексный коэффициент DFT на частоте основной гармоники
- `Σ hann` — сумма коэффициентов оконной функции (нормировка амплитуды)
- Множитель 2 — переход от двустороннего спектра к пиковой амплитуде

### 5.4. Преобразование Фортескью (Fortescue)

Для трёхфазной системы фазоров `Va, Vb, Vc`:

```
         [1   1     1   ] [Va]
[V0]   1 [1   a     a²  ] [Vb]
[V1] = - [1   a²    a   ] [Vc]
[V2]   3

где a = e^(j·2π/3) = -0.5 + j·√3/2
```

### 5.5. Магнитуды симметричных составляющих

Для токов (каналы 0-2):
```
i0, i1, i2 = abc_to_seq(phasor_IA, phasor_IB, phasor_IC)
|I1|[t] = |i1|   // прямая последовательность
|I2|[t] = |i2|   // обратная последовательность
|I0|[t] = |i0|   // нулевая последовательность
```

Для напряжений (каналы 3-5):
```
u0, u1, u2 = abc_to_seq(phasor_UA, phasor_UB, phasor_UC)
|U1|[t] = |u1|
|U2|[t] = |u2|
|U0|[t] = |u0|
```

## Результат
```
symseq = [|I1|, |I2|, |I0|, |U1|, |U2|, |U0|]   // форма (6, T)
```

## Финальный 12-канальный тензор
```
tensor = [IA, IB, IC, |I1|, |I2|, |I0|, UA, UB, UC, |U1|, |U2|, |U0|]
         // форма (12, T)
```

## Параметры
| Параметр | Значение | Описание |
|---|---|---|
| `fs` | из CSV | Частота дискретизации [Гц] |
| `f0` | 50.0 | Основная частота [Гц] |
| `window_cycles` | 1 | Число периодов в окне DFT |

## Пример
При `fs = 2000` Гц, `f0 = 50` Гц:
- `period = round(2000/50) = 40` отсчётов
- `window_len = 40` отсчётов = 20 мс = 1 период
- `k = round(50 · 40 / 2000) = 1` — индекс основной гармоники

## Свойства
- **Time-varying**: каждый отсчёт имеет свои магнитуды симметричных составляющих
- **Оконная функция Ханна**: снижение спектральных утечек
- **Преобразование Фортескью**: стандартный метод анализа несимметрии
- **Инвариантность к сдвигу фаз**: магнитуды не зависят от абсолютной фазы
