# Этап 6: Нормализация

## Два режима нормализации

### Режим 1: Standard (статистическая)

#### Для сигналов (per-channel StandardScaler)
Для каждого канала `c`:

```
μ_c = (1/(N·T)) · Σ_{i=0}^{N-1} Σ_{t=0}^{T-1} X[i, c, t]

σ_c = sqrt( (1/(N·T)) · Σ_{i=0}^{N-1} Σ_{t=0}^{T-1} (X[i, c, t] - μ_c)² )

X_norm[i, c, t] = (X[i, c, t] - μ_c) / (σ_c + 10⁻⁸)
```

где:
- `N` — число образцов в датасете
- `T` — длина последовательности (SEQ_LENGTH)
- `c` — индекс канала

#### Для расстояния (MinMaxScaler)
```
d_min = min(d_i)
d_max = max(d_i)

d_norm[i] = (d_i - d_min) / (d_max - d_min + 10⁻⁸)
```

#### Обратное преобразование
```
d_km = d_norm · (d_max - d_min) + d_min
```

---

### Режим 2: Per-Unit (физическая)

#### Базисные величины
```
Ubase = Unom · 1000 / √3          // фазное напряжение [В]

Ibase = S_base · 10⁶ / (√3 · Unom · 1000)   // базисный ток [А]
```

где:
- `Unom` — номинальное линейное напряжение [кВ]
- `S_base` — базисная мощность [МВА]

#### Нормировка сигналов
```
// Фазные токи (каналы 0-2)
I_pu = I_A / Ibase

// Для 6-канального тензора:
U_pu = U_kV / Unom

// Для 12-канального тензора:
// Фазные напряжения (каналы 6-8)
U_pu = U_kV / Unom

// Магнитуды токов симм. сост. (каналы 3-5)
|I1|_pu = |I1| / Ibase
|I2|_pu = |I2| / Ibase
|I0|_pu = |I0| / Ibase

// Магнитуды напряжений симм. сост. (каналы 9-11)
|U1|_pu = |U1| / Unom
|U2|_pu = |U2| / Unom
|U0|_pu = |U0| / Unom
```

#### Нормировка расстояния
```
d_pu = d_km / L_km
```

где `L_km` — длина линии [км].

#### Обратное преобразование
```
d_km = d_pu · L_km
```

## Параметры
| Параметр | Значение | Описание |
|---|---|---|
| `NORMALIZATION_MODE` | 'standard' | 'standard' или 'pu' |
| `Unom` | 110.0 кВ | Номинальное напряжение |
| `L_km` | 50.0 км | Длина линии |
| `S_base` | 100.0 МВА | Базисная мощность |

## Сравнение режимов
| | Standard | Per-Unit |
|---|---|---|
| Требует fitted scalers | Да | Нет |
| Зависит от датасета | Да | Нет |
| Физическая интерпретация | Нет | Да |
| Применимость к новым линиям | Ограничена | Универсальна |
| Сохраняет пропорции амплитуд | Нет | Да |
