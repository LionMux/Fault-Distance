# Этап 3: Детекция момента короткого замыкания (detect_t0_rms)

## Назначение
Автоматическое определение момента наступления КЗ (t₀) по изменению RMS токов и напряжений.

## Математика

### Окно анализа
```
k = fs / (4 · f_net)   // длина окна = четверть периода сети [отсчёты]
```

### RMS в окне
```
RMS(x, start, end) = sqrt( (1/(end-start)) · Σ_{n=start}^{end-1} x[n]² )
```

### Отношения для каждой позиции i
Для каждого отсчёта `i` (от `k` до `N-k`) вычисляются:

**Токи** (максимум по трём фазам):
```
I_pre(i)  = max( RMS(ia, i-k, i),   RMS(ib, i-k, i),   RMS(ic, i-k, i) )
I_post(i) = max( RMS(ia, i, i+k),   RMS(ib, i, i+k),   RMS(ic, i, i+k) )

I_ratio[i] = I_post(i) / (I_pre(i) + ε)   если I_pre > 10⁻⁶
           = 1.0                           иначе
```

**Напряжения** (минимум по трём фазам):
```
U_pre(i)  = min( RMS(ua, i-k, i),   RMS(ub, i-k, i),   RMS(uc, i-k, i) )
U_post(i) = min( RMS(ua, i, i+k),   RMS(ub, i, i+k),   RMS(uc, i, i+k) )

U_ratio[i] = U_post(i) / (U_pre(i) + ε)   если U_pre > 10⁻⁶
           = 1.0                           иначе
```

### Условие обнаружения КЗ
```
КЗ обнаружено в позиции i, если:
    I_ratio[i] > (1 + η_I)    AND    U_ratio[i] < η_U
```

где:
- `η_I = 0.5` — порог роста тока (ток вырос более чем на 50%)
- `η_U = 0.85` — порог падения напряжения (напряжение упало более чем на 15%)

### Финальный t₀
```
skip = 2 · k   // пропускаем первые 2 окна (избежание ложного срабатывания)

candidates = { i | I_ratio[i] > 1.5  AND  U_ratio[i] < 0.85  AND  i ≥ skip }

t₀ = min(candidates)   // первое срабатывание
```

## Параметры
| Параметр | Значение | Описание |
|---|---|---|
| `fs` | из CSV | Частота дискретизации [Гц] |
| `f_net` | 50.0 | Сетевая частота [Гц] |
| `η_I` | 0.5 | Порог роста тока |
| `η_U` | 0.85 | Порог падения напряжения |

## Пример
При `fs = 5000` Гц, `f_net = 50` Гц:
- `k = 5000 / (4 · 50) = 25` отсчётов = 5 мс
- `skip = 50` отсчётов = 10 мс
- Условие: ток вырос >50% И напряжение упало >15%

## Свойства
- **Двухкритериальная проверка**: ток + напряжение (снижение ложных срабатываний)
- **Адаптивность**: пороги относительные (отношения, не абсолютные значения)
- **Робастность**: skip первых 2 окон защищает от стартовых переходных процессов
